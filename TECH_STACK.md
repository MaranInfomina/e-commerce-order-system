## Architecture notes

- **One origin, no CORS.** Only `nginx` publishes the application port(s); the frontend and API share an origin through nginx's routing.
- **JWT auth, not session-based.** A custom guard (`app/Auth/JwtGuard.php`) verifies bearer tokens and checks a Redis denylist on every request — no Sanctum/Passport.
- **Money is always integer cents** (`price_cents`) — no floating-point currency anywhere.
- **Async order flow.** Checkout commits synchronously (stock decrement + order write in one transaction), then dispatches a `ProcessPayment` → `SendOrderConfirmation` job chain onto RabbitMQ; a trace context (W3C `traceparent`) is captured at dispatch time so Jaeger shows one connected trace spanning both the sync request and the async chain.
- **Everything runs in containers** — no PHP, Composer, or Node needed on the host; `scripts/setup.sh` / `scripts/setup.ps1` are the only setup step.
